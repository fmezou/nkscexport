***************
Developer Guide
***************
.. sectionauthor:: Frédéric MEZOU <frederic.mezou@free.fr>

This manual is designed for a *developer audience* to enhance features
and contributing to the project.This documentation describes scripts,
modules,exceptions,classes, functions and data composing the project.

The project is written only in Python, and it composed of several
components. The main component is a script (:mod:`darkbridge.main_cli`)
in charge of the user interface (in text mode) and operations scheduling.
