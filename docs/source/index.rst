########################
DarkBridge documentation
########################

This is the documentation for **DarkBridge** |release|, last updated |today|.

This application convert sidecar files (``.nksc``) from Nikon NX Studio in
sidecar files compliant with Darktable. The package includes a script
:command:`darkbridge` (:mod:`darkbridge.main_cli`) to use the package in
a terminal.
